## Interplay checks

- **Launcher dies while the menu waits for the ack:** the operating system closes the socket, so the worker reports `closed` (`control_thread.lua:197-199`). On the next frame `poll_start` returns an error (`companion_host.lua:1069-1081`), and `fail` replaces the waiting screen with a closable error screen (`practice_menu.lua:264-273`).
- **Launcher hangs:** after 120 s the timeout calls `fail(TIMEOUT)`, which shows the same closable screen.
- **Error screen fails to build:** the engine has already removed the waiting screen (`:1355`), and the leftover `true` flag is cleared. The player is left on the plain main menu, unpaused, not stuck.
- **Update loop breaks:** after 5 update errors, `uninstall` closes the waiting screen (F4).
- **Tests and evidence:** the four new cases match the real engine's behaviour. `work/overlay-args-verify2.txt` shows all 14 suites with exit code 0. No test covers the transport across an idle connection close or a worker rebuild, which is why H1 was missed.
